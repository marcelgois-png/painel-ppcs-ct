# PPCs do CT · Painel de acompanhamento

Painel da Direção do Centro de Tecnologia da UFPB que acompanha a atualização dos projetos pedagógicos dos 10 cursos de graduação do CT, a partir da tramitação dos processos no SIPAC, à luz do Manual de Elaboração e Atualização de PPC (CCA/PRG, 2025).

- Arquivo único: `index.html`, no padrão dos painéis HTML da Direção do CT.
- Dados: consulta pública do SIPAC em 24/11/2026.
- Publicação: GitHub Pages, ramo `main`, raiz.
